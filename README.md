# Cultural & Creative Society — PHP Site

A lightweight PHP website (no database). All content is loaded from `data/site.json`.

## Pages
- `index.php` — Home (hero + highlights + recent gallery)
- `about.php` — About us
- `team.php` — Team
- `gallery.php` — Gallery with filter + lightbox
- `publications.php` — Publications
- `contact.php` — Contact info

## Run locally
Requires PHP 7.4+:
```
cd ccs-site
php -S localhost:8000
```
Open http://localhost:8000

## Deploy
Upload the `ccs-site/` folder to any PHP-enabled host (cPanel, Hostinger, InfinityFree, XAMPP, etc.).

## Edit content
Open `data/site.json` and change anything — society name, team members, gallery images, publications, contact info. No code changes needed.
